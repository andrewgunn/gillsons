# Gillson's Brasserie menus

A redesigned menus page for Gillson's Brasserie, Ecclesall Road, Sheffield. Static HTML, CSS and JS with no build step.

- `index.html`: page, styles and behaviour
- `menus.js`: menu data (à la carte, lunch, Sunday, children, wine, bar)
- `img/`: photography as WebP at 800px and 1400px wide, plus the logo

Live at https://andrewgunn.github.io/gillsons/
