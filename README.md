# Gillson's Brasserie — menus redesign

A redesigned menus page for Gillson's Brasserie, Ecclesall Road, Sheffield. Static HTML/CSS/JS, no build step.

- `index.html` — page, styles and behaviour
- `menus.js` — menu data (à la carte, lunch, Sunday, children, wine, bar)
- `img/` — photography and logo

Live: https://andrewgunn.github.io/gillsons/
